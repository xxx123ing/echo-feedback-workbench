1. 优先区分已知事实、未知条件、待验证假设；禁止把来源标注或已知重复关系再列为未知。
2. 只有明确因果证据才使用“导致”；否则写“随后”或“可能相关”。
3. 缺失项非空时，不得同时输出“未发现明确缺失项”。
4. 补一条明确要求计算比例的独立用例，弥补E06条件式判据未触发；旧判据和成绩保留，不事后篡改。
