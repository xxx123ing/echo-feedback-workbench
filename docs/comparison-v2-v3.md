## 实施与取舍
已更新issue-card-v3提示词；保留旧输出、输入快照和两轮逐项审阅。引用校验仍为原文字符串匹配，不是事实判定。3项现有AI校验测试通过。
下一步优先把已知事实、未知条件、方案假设分成独立字段，并增加一致性检查；不继续简单堆叠提示词。对原判据未覆盖的质量问题另立指标，不篡改本次成绩。未经进一步验证不自动采纳生成建议。
