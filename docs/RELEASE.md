## 自行部署到GitHub Pages
1. 创建空的Public仓库，不额外初始化README、许可或.gitignore。
2. 上传源码包的全部内容，包含.github目录；不上传私人数据或.env.local。
3. Settings → Pages，选择GitHub Actions。仓库已含构建与发布工作流。
4. 部署成功后检查演示链接，再将实际仓库和演示地址补入README。
5. 部署后检查Actions结果及线上页面。
